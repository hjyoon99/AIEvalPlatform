# 대시보드 리소스 추가·삭제 가이드

## 프로젝트

화면 오른쪽 위 `프로젝트 관리` 버튼을 누른다.

추가:

1. 프로젝트 이름과 도메인을 입력한다.
2. 설명은 선택적으로 입력한다.
3. `새 프로젝트 추가`를 누른다.

삭제:

1. 프로젝트 관리 목록에서 대상 프로젝트의 `삭제`를 누른다.
2. 경고 내용을 확인하고 승인한다.

프로젝트를 삭제하면 소속 시나리오, 평가 정책, 어댑터와 해당 어댑터의 Job이 함께 삭제된다. 기존 EvalRun과 EvalResult는 비교 이력을 위해 보존되며 프로젝트 연결만 해제된다.

`QUEUED` 또는 `RUNNING` 평가가 있는 프로젝트는 삭제할 수 없다. 평가가 끝난 후 다시 시도한다.

## 평가 실행

왼쪽 첫 번째 `⌁ 평가 실행` 메뉴에서 최근 실행을 관리한다.

- 실행 행을 선택하면 아래 Result Explorer에서 상세 결과를 확인한다.
- 실행 행 오른쪽 `×`를 누르면 완료된 Run과 Case, Job, 결과를 삭제한다.
- `QUEUED` 또는 `RUNNING` 상태의 Run은 처리 중 데이터 손상을 막기 위해 삭제할 수 없다.

## 시나리오

왼쪽 `◫ 시나리오` 메뉴를 사용한다.

추가 방법:

- `AI 시나리오 생성`: Agent Engine이 여러 초안을 생성한다.
- `+ 직접 추가`: 제목, 질문, 기대 답변을 사람이 입력한다.

직접 추가한 시나리오는 `DRAFT`로 생성된다. 카드를 선택하여 루브릭과 테스트 출력 등을 편집하고 승인 또는 거절할 수 있다.

삭제:

1. 시나리오 카드 아래 `삭제`를 누른다.
2. 확인창에서 승인한다.

삭제된 시나리오는 향후 실행 대상에서 제거된다. 이미 완료된 EvalRun의 입력과 결과는 해당 Run에 저장된 스냅샷으로 유지된다.

## 평가 정책

왼쪽 `⚙ 평가 정책` 메뉴를 사용한다.

추가:

1. 정책 이름과 통과 기준을 입력한다.
2. `+ 평가지표 추가`로 필요한 지표를 추가한다.
3. 지표 이름, 설명, 가중치와 필수 여부를 설정한다.
4. 전체 가중치 합을 `1.0`으로 맞춘다.
5. `평가 정책 저장`을 누른다.

지표 삭제:

- 편집 중인 지표 행의 `지표 삭제`를 누른다.
- 정책에는 최소 한 개의 지표가 필요하다.

정책 삭제:

- 오른쪽 `저장된 정책` 목록에서 `삭제`를 누른다.

기존 EvalRun은 실행 당시 `policySnapshot`을 저장하므로 정책을 삭제해도 완료된 평가의 기준 정보가 유지된다.

## 평가 어댑터

왼쪽 `⇄ 평가 어댑터` 메뉴를 사용한다.

추가:

1. 상단에서 프로젝트를 선택한다.
2. 어댑터 이름과 환경을 입력한다.
3. `등록 및 SDK Key 발급`을 누른다.
4. 한 번만 표시되는 `aieval_...` SDK Key를 복사한다.

삭제:

1. `평가 대상`에서 삭제할 어댑터를 선택한다.
2. 오른쪽 어댑터 상태 영역의 `어댑터 삭제`를 누른다.
3. 경고창에서 승인한다.

어댑터를 삭제하면 SDK Key가 즉시 무효화되고 소속 SdkJob도 함께 삭제된다. 실행 중인 Adapter Worker는 이후 인증 오류를 받으므로 함께 중지하거나 새 키로 재설정해야 한다.

처리 중인 자동 평가 SdkJob이 있는 어댑터는 삭제할 수 없다. 연결 테스트용 Job 또는 완료된 Job만 있는 경우에는 삭제할 수 있다.

## 삭제 확인 원칙

모든 삭제 작업은 브라우저 확인창을 거친다. 운영 환경에서는 다음 권한 정책을 추가하는 것이 권장된다.

- 프로젝트 삭제: 관리자만 허용
- 평가 정책 및 어댑터 삭제: 프로젝트 관리자 허용
- 시나리오와 완료 Run 삭제: 평가 담당자 허용
- 삭제 감사 로그와 복구 보존 기간 설정

현재 MVP는 별도 사용자 권한 모델과 휴지통을 제공하지 않으며 삭제는 즉시 적용된다.
